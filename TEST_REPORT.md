# Verification

Automated tests cover cutoff boundaries, future-bar isolation, explicit imported timezones, duplicate securities/events, next-session execution, whole lots, affordability, suspension, limit-up, bounded slippage, T+1, gross cash dividend entitlement, completed-run idempotency, insufficient-sample metrics, API persistence, concurrent same-version steps, snapshot/export, cross-origin rejection and invalid AI weights/evidence.

Real-source and hosted verification results are added only after they have completed. No production model calls have been made. Browser visual QA may be unavailable in restricted environments; source syntax and API tests are separate checks and must not be represented as visual testing.
